Universal Tag

Make your site readable by AI agents.

No CMS, no plugin, no code changes to your pages beyond one script tag. Works on static sites, custom-coded sites, anything that runs no WordPress.

Part A

Paste one script tag

Enter your TETA+PI entity ID — find it on your entity's dashboard under Settings, or in the URL of your profile page (app.tetapi.dev/entities/YOUR_ID). Don't have one yet? Register your entity first.

This is your entity's public ID — it is not a secret and is safe to publish on your site.

add to <head> 
<script async src="https://tetapi.dev/tag.js" data-entity="YOUR_ENTITY_ID"></script>

This script injects schema.org structured data (JSON-LD) describing your entity and sends one lightweight indexing beacon per page load. No cookies, no cross-site tracking, no persistent identifiers — deliberately less than a typical analytics script.

⚠️

Part A alone is a partial signal. A script tag can inject structured data into the page for agents that execute JavaScript, but it cannot create files at your domain's /.well-known/ root — that needs server-level access, which a client-side script never has. Agents that fetch /.well-known/agent.json directly (many do, without running JS) won't see anything until you complete Part B below. For full agent-readability, do both.

Part B — optional, ~5 minutes

Add one DNS record

This proves domain ownership and lets TETA+PI serve real /.well-known/agent.json, agent-card.json, and llms.txt from your domain root — reachable by every agent, not only ones that run JavaScript.

1

Add a DNS record

CNAME _ttpi-agent.yourdomain.com → verify.tetapi.dev, or if your DNS provider doesn't support CNAME at that label, a TXT record: yourdomain.com "ttpi-verify=YOUR_ENTITY_ID".

2

Add a redirect rule at your host

One line routing /.well-known/* to TETA+PI's proxy. Exact syntax depends on your host — see the links below for Vercel, Netlify, Cloudflare Pages, Apache, and Nginx.

3

We verify automatically

Once the DNS record is live, TETA+PI detects it within ~30 minutes and verifies your entity via Domain Ownership — the same method used elsewhere on the platform. No separate approval step.

Vercel (vercel.json) Netlify (_redirects) Cloudflare Pages Apache (.htaccess) Nginx
